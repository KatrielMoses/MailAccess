OPEN SOURCE / SELF-HOSTABLE / AUTHORIZED USE

Email intelligence
without the black box.

Investigate email addresses and harvest organizational mailboxes across the open web. MailAccess turns scattered signals into a defensible, exportable view of exposure.

Install MailAccess → See the commands
$pip install mailaccess

01 / CORE COMMANDS

Two commands.
The whole signal.

Start with a person. Or start with a domain. MailAccess gives both paths the same structured, repeatable treatment.

01EMAIL INVESTIGATION

Investigate an address

Fan out across breach intelligence, social platforms, DNS, reputation, and identity signals.

investigate
$ mailaccess investigate you@example.com → identity graph + breach checks → 2500+ platform coverage ✓ structured findings ready
02DOMAIN HARVESTING

Harvest an organization

Find public-facing employee addresses across archives, certificates, code, registries, and search sources.

harvest-emails
$ mailaccess harvest-emails --domain company.com → 8 concurrent discovery sources → confidence-scored addresses ✓ export to CSV or JSON

02 / CAPABILITIES

One address.
