# Sponsor logos

Logo files for [docs/sponsors.md](../../docs/sponsors.md). None are in use yet: that page lists sponsors as text links. The README sponsor banners live in `assets/sponsor-*.png`.

Conventions:

- One file per sponsor, named after the company, for example `netlas.png`.
- PNG or SVG, transparent background.
- Sized so it renders cleanly at **60px height** (the fixed height used on the page).
- Prefer a horizontal lockup (wordmark + icon) over an icon alone.

Ask the sponsor for their official press-kit asset rather than scraping one off their site.
